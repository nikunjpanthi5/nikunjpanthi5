## 🚀 Featured Projects

### 🛒 Commerce Customer Intelligence

An end-to-end Data Science and Machine Learning project using online retail transaction data to develop customer analytics and intelligent recommendation solutions.

**Key Components:**

- Customer segmentation using RFM analysis
- Customer churn prediction
- Machine learning model comparison and evaluation
- Feature engineering and customer behavior analysis
- Item-based and personalized product recommendation
- FastAPI backend and Streamlit application
- Interactive business analytics with Power BI

**Best reported model:** Gradient Boosting

**Validation ROC-AUC:** 0.8943

**Tech Stack:** Python · Pandas · NumPy · Scikit-learn · FastAPI · Streamlit · Power BI

🔗 **[Explore Repository →](https://github.com/nikunjapanthi5/ecommerce-customer-intelligence)**
