## 🚀 Featured Project

### 🛒 ecommerce-customer-intelligence

An end-to-end Data Science and Machine Learning project built using online retail transaction data.

**What I've explored:**

- Customer segmentation using RFM analysis
- Customer churn prediction
- Machine learning model comparison and evaluation
- Customer similarity analysis
- Product recommendation approaches
- API and interactive application development

**Best reported model performance:** ROC-AUC 0.894 (Gradient Boosting).

**Tech Stack:** Python · Pandas · NumPy · Scikit-learn · XGBoost · FastAPI · Streamlit
